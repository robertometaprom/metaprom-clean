# Membership Dashboard — UX Brief

**Status:** Draft — not approved for implementation

## User goal

Understand what they have purchased and continue creating — not manage AI settings.

## Layout (proposed)

- Hero: *Tus comerciales*
- Stats: creaciones · compras HD · última actividad
- CTA: **Crear nuevo comercial** → Studio
- List of paid assets with download

## Explicitly excluded

- Model selection, prompts, credits, technical settings.
